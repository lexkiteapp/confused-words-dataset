# Commonly Confused English Words: an open dataset (Lexkite)

82 groups of English words that learners often mix up (affect/effect, borrow/lend, lie/lay…). Each group lists every word with its part of speech, a short English definition, an original example sentence, a typical mistake with its correction and a memory tip.

Built by the **Lexkite Editorial Team** from Lexkite's own editorial content. It contains **no user data**.

- Source page (always the latest version): https://lexkite.com/en/research/confused-words/
- Files: [`confused-words.csv`](confused-words.csv) · [`confused-words.json`](confused-words.json)
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Creator: Lexkite Editorial Team. Publisher: Lexkite.
- Keywords: English, ESL, EFL, commonly confused words, learner errors, vocabulary, CEFR, education

## Columns

| Column | Meaning |
|---|---|
| `id` | Stable slug of the group |
| `words` | Words in the group, separated by ` / ` |
| `parts_of_speech` | Part of speech of each word, same order |
| `pos_pattern` | Pattern of parts of speech (e.g. `n ↔ v`) |
| `definitions` | Short English definition per word, separated by ` \| ` |
| `example` | Original example sentence per word, separated by ` \| ` |
| `typical_mistake` / `correction` | A common learner mistake and its corrected form |
| `mistake_note` | Why the mistake is wrong |
| `mistakes_documented` | Number of documented mistakes for the group |
| `memory_tip` | A short tip to remember the difference |
| `related_lesson` | Related Lexkite lesson slug |

## Limitations

This is an **editorially curated list**, not a measured frequency of learner errors. The order and selection reflect editorial judgement, not corpus statistics.
